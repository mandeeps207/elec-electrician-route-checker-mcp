# Release 1 0 0

Initial read-only release of Electrician Route Checker by Elec Training Ltd.

Four educational tools cover likely electrician routes, qualification-stage explanations, NVQ workplace progression and broad route comparison. The service uses stateless Streamable HTTP and requires no login. It has no contact collection, database, payment, CRM writes, email or form submissions.

The provider fact base is dated 17 November 2026. Advice preserves the distinction between technical learning and occupational competence, the restricted Level 3 NVQ placement guarantee, separately charged support and external NET assessment.

This release is prepared for publisher review. Public submission is not authorised until the build and test results are approved.
